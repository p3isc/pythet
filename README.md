# pythet
dumb little ASCII cat that does your bidding, linux (or bash) only, best used as a yakuake profile that autoruns the script

info/dependencies
  written in python
  the thing starts spotatui on boot so prolly download and log into that
  
features
  spotatui control ("play <song>") and it will play the first on the search
  stop song ("stop song") stop song
  remember ("remember <something>") and then it will save it in a notes file
  recall ("recall") prints notes text file
  tells you info ("what is <thing>) pulls first results intro paragraph from simple English wikipedia
  tells you info in German ("was ist <thing>") pulls first results intro paragraph from German wikipedia
  search things ("search <thing>" and ("search url <thing") search from Google or whatever and search direct url
  settings ("settings") edit stored settings in config
    browserurl ("settings" then "browserurl") change search indexer (it will auto fill if you say Google or duckduckgo)
